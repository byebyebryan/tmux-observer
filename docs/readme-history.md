## Current selection

**0.1.0a24**, with delta delivery disabled. The

The **0.6.0a9 source/private candidate** adds an explicit
[complete-view feed pilot](../docs/view-feed-pilot.md) with experimental Mesh
**0.1.0a24**. `fleet --transport mesh --view-feed` selects it; the ordinary
full-view Mesh route remains the default. Candidate qualification and the
measured cost decision are separate from managed selection.

The exact a9 prerelease inputs are prepared in the
[public supply record](../docs/evidence/2026-10-23-public-delivery/README.md).
The wheel build source, its qualification source and the source release tip
are recorded separately.

The **0.6.0a8 source/private candidate** adds an optional
[owner preparation facade](../docs/mesh-preparation.md) for Mesh a18.
[Actual IPC/SSH qualification](../docs/evidence/2026-10-14-preparation/README.md)
retains the existing Fleet guard: preparation removes no work in that path.
This candidate does not change the managed selection below.

Released **0.6.0a7** owns cached native acquisition and integrates Mesh
**0.1.0a15** through its public publisher helper, pure Observer profile and
explicitly bound readers/stream guards. The same lazy factory serves local and
fixed SSH publication. [Publisher acceptance](../docs/evidence/2026-10-12-publisher-integration/README.md)
separates source, artifact, resource, consumer and managed gates. Frozen wire
contracts are unchanged.

Passive tmux observation and shared prepared views for local and remote clients.
The host-local core reads session metadata; an owner service publishes it.
A separate fleet reader uses Mesh Plus for state delivery and adds observations
from the viewing desktop. [Tmux Plus](https://github.com/byebyebryan/rofi-tmux-plus)
consumes those views and sends explicit intent to a separate action client.

This is maintained generic tmux tooling. Agent Plus now opens native provider
managers directly and has no Tmux runtime dependency. New work here needs a
concrete tmux workflow or consumer; lower agent-runtime relevance does not
establish that existing owners, fleet readers or action clients are unused.
